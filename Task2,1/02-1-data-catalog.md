## Набор A

1. Произведения жанра «Научная фантастика» — полные кортежи.
2. Список названий.
3. Названия книг, опубликованных до 1950 года и короче 300 страниц.
4. Словарь «автор → список его произведений» (полные кортежи).
5. Среднее число страниц по коллекции.

## Набор B

1. Словарь «должность → средний стаж».
2. Строки `"Фамилия: Зарплата"` для зарплаты выше 5000 и стажа менее 10 лет.
3. Словарь «фамилия → число систем, за которые сотрудник отвечает».
4. Словарь «фамилия → премия»: 10 % от зарплаты, при стаже более 5 лет — 15 %.
5. Системы, за которые отвечают меньше двух сотрудников.
6. Список словарей по сотрудникам: фамилия, должность, стаж, зарплата, число систем, премия.

Базовый объём — набор A. Набор B — по указанию преподавателя.

## Задание

1. Модули: `data.py` (данные), `solution_loops.py` (циклы), `solution_comprehensions.py` (comprehensions), `main.py` (запуск и вывод).
2. Каждый интерфейс своего варианта — в обеих версиях, с одинаковыми именами функций.
3. `tests/test_equivalence.py`: для каждого интерфейса обе версии дают один результат на данных из `data.py`.
4. `tests/test_edge_cases.py`: агрегация на пустой коллекции; фильтрация без единого совпадения. Среднее сравнивать через `pytest.approx`.
5. Один тест с ответом, посчитанным вручную и записанным в тест константой.
6. `main.py` печатает результат: словари построчно, числа с фиксированной точностью, списки по одному элементу в строке.
7. Отчёт на одну страницу: для каждого интерфейса — какая запись предпочтительна и почему.

## Требования

- Функция принимает коллекцию и возвращает новый объект.
- `data.py` не считает и не печатает.
- У обеих версий есть аннотации типов.
- `pytest` указан в `requirements.txt`. `pytest -q` запускается из корня проекта.
- Тесты не печатают и не меняют данные из `data.py`.

## Приёмка

- `pytest -q` проходит; команда запуска есть в `README.md`.
- Совпадение двух версий подтверждено тестом.
- В тесте с известным ответом видно, откуда взято ожидаемое значение.
- Поведение агрегации на пустой коллекции зафиксировано тестом.
